# crime-data-cleaning-mysql
A data cleaning project using MySQL Workbench to identify, handle, and standardize inconsistencies in a crime dataset. This mini project have shown that data cleaning is part of important of data analysis and mostly it tooks hours of cleaning the data before continue to analysis. 

## Data & Tools:
- **Dataset**: Sourced from Kaggle, consisting of approximately 3,000 rows with various data quality issues and inconsistencies that require cleaning.
- **Database**: MySQL workbench.
- **Techniques Used**: Basic query.

## Approach & Methodology: 
- **Cleaning**: Handle missing value then replace it with NULLS, Remove duplicates, data type conversion, reformatting date, and data standardization.

## Key SQL Techniques:
- CASE WHEN to replace value with others value.
- ALTER TABLE to modify columns.
- RAGEXP to reformatting date.
- Aggregate function to show data distribution.
- CTE's to remove duplicates.
